## 📖 About The Project

**Cafephile** is a coffee shop website created as my first frontend development project.

The website features a café-inspired design with multiple pages for exploring the café, viewing the menu, reading blog posts, and finding contact information.

This project represents my first step into frontend development and helped me gain practical experience in building and styling a multi-page website.

🌐 **Explore the live website:** [cafephile.netlify.app](https://cafephile.netlify.app/)

## ✨ Features

- ☕ Coffee shop-inspired website design
- 🏠 Home page
- 📖 About page
- 🍵 Menu page
- 📝 Blog page
- 📄 Individual blog details page
- 📩 Contact page
- ❌ Custom 404 error page
- 🎨 Custom CSS styling
- ⚡ JavaScript for frontend interactions
- 🔗 Multi-page website navigation
- 🌐 Live website deployment through Netlify

## 🚀 Getting Started

Follow these steps to run Cafephile on your local machine.

### Prerequisites

- A modern web browser
- Visual Studio Code (recommended)
- Live Server extension (optional)

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/Harashishsingh/Cafephile.git
```

**2. Navigate to the project directory**

```bash
cd Cafephile
```

**3. Open the project in VS Code**

```bash
code .
```

**4. Run the website**

Open `index.html` in your browser, or use the Live Server extension in VS Code.

No backend setup or package installation is required to run the basic static frontend.
